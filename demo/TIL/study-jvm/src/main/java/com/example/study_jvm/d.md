[지금까지 학습을 완료한 내용 - 다시 설명할 필요 없음]
1. 스레드 기초: Thread/Runnable 개념, start()와 run()의 차이, 컨텍스트 스위칭 개념
2. 가시성(Visibility) 문제: CPU 캐시/레지스터로 인한 문제, volatile의 역할과 한계, VisibilityTest 코드로 무한루프 재현 및 volatile로 해결 확인 완료
3. 원자성(Atomicity) 문제: count++의 lost update 문제, AtomicityTest 코드로 재현 완료(스레드 10개 x 10만 번 반복 시 예상값보다 훨씬 작은 값이 나오는 것 확인)
4. CAS(Compare-And-Swap)와 AtomicInteger: CAS 알고리즘 동작 원리(비교 후 교체, 실패 시 재시도 루프), CPU 하드웨어 레벨의 캐시라인 락, 소프트웨어 락(블로킹)과 CAS(논블로킹, 스핀)의 차이, AtomicInteger로 원자성 문제 해결 확인 완료(정확히 예상값과 일치)
5. happens-before 규칙: 개념(물리적 실행 순서가 아니라 결과의 가시성을 보장하는 계약), volatile 변수 규칙과 join 규칙을 앞선 실습과 연결해서 이해 완료
6. synchronized: 메소드 방식과 블록 방식 문법, 락(모니터) 객체의 의미, synchronized로 원자성 문제 해결하는 코드 작성 및 실행 결과 확인까지 완료
7. ReentrantLock: synchronized와 비교하며 학습 완료 (tryLock, 공정성 옵션 등 synchronized에 없는 기능 포함), 코드 실습 완료
8. 데드락(deadlock): 두 락을 서로 다른 순서로 잡을 때 발생하는 상황을 코드로 직접 재현 완료
